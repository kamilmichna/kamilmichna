## Overview

GitHub's design is functional and information-dense. The dark theme with subtle green accents creates a focused developer environment. Every element serves a purpose.

## Colors

Dark surfaces (#0D1117) with green (#238636) for positive actions. The palette is restrained, using color only where it adds meaning.

## Typography

System fonts at small sizes maximize information density. GitHub's interface packs a lot of data into compact spaces.

## Do's and Don'ts

1. **Do** prioritize information density for developers
2. **Don't** add decorative elements — function over form
3. **Do** use green for positive actions only
4. **Don't** use large font sizes — keep it compact
