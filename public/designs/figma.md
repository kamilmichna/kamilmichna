## Overview

Figma's design system is vibrant and approachable. Multiple bold colors create a playful, creative atmosphere that reflects the tool's design-focused purpose. Rounded corners soften the interface.

## Colors

A multi-color palette with purple, orange, and green as primaries. Each color serves a distinct purpose, creating a rich but organized visual language.

## Typography

Clean Inter usage with moderate weights. The system avoids extremes, maintaining a friendly, accessible feel throughout.

## Do's and Don'ts

1. **Do** use color purposefully — each hue has meaning
2. **Don't** mix too many colors in one view
3. **Do** embrace rounded corners for approachability
4. **Don't** sacrifice usability for aesthetics
