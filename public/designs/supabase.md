## Overview

Supabase's design is modern, developer-friendly, and confident. The green accent on dark surfaces creates a tech-forward feel. Code fonts and dense layouts speak to the developer audience.

## Colors

Green (#3ECF8E) on dark surfaces (#1C1C1C). The green represents growth and open-source values.

## Typography

Inter for UI, JetBrains Mono for code. The dual-font system clearly separates interface from technical content.

## Do's and Don'ts

1. **Do** use green for positive states and actions
2. **Don't** make the interface too corporate — it's open source
3. **Do** embrace code fonts for technical content
4. **Don't** sacrifice developer experience for aesthetics
