## Overview

Discord's design balances playfulness with functionality. The signature blurple (#5865F2) creates a friendly, approachable feel. Rounded corners and subtle gradients add warmth to the dark interface.

## Colors

Dark grays (#313338, #2B2D31) with Discord's blurple as the primary accent. Bright, saturated colors for reactions and status indicators.

## Typography

Clean, readable fonts at moderate sizes. The system balances information density with approachability.

## Do's and Don'ts

1. **Do** use blurple for primary actions and highlights
2. **Don't** make the interface too serious — Discord is fun
3. **Do** embrace rounded corners for friendliness
4. **Don't** use harsh contrasts — keep it smooth
