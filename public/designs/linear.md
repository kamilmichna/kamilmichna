## Overview

Linear's design system embodies precision and focus. Dark surfaces with high-contrast text create a tool that disappears into the background, letting the work take center stage. Every element is intentionally minimal.

## Colors

The dark palette (#1B1B1F base) with the signature Linear purple (#5E6AD2) creates a sophisticated developer environment. High contrast whites on dark backgrounds ensure readability.

## Typography

Inter with tight spacing creates a dense, information-rich interface. Small font sizes maximize content density while maintaining clarity.

## Do's and Don'ts

1. **Do** keep interfaces dense but not cramped
2. **Don't** use decorative elements — every pixel serves a purpose
3. **Do** maintain consistent 12px vertical rhythm
4. **Don't** add shadows or gradients — flat is the way
