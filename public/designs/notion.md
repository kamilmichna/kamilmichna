## Overview

Notion's design is intentionally understated. Warm grays and minimal decoration create a canvas that lets content shine. The system prioritizes readability and focus over visual flair.

## Colors

Warm neutrals (#37352F text, #F7F6F3 backgrounds) create an inviting, paper-like feel. Green for success, yellow for warnings — all muted and organic.

## Typography

Inter at moderate weights with comfortable line-heights. The system prioritizes reading comfort over visual impact.

## Do's and Don'ts

1. **Do** let content be the hero — the UI should disappear
2. **Don't** add visual noise — Notion is a blank canvas
3. **Do** use warm tones for a welcoming feel
4. **Don't** use heavy weights except for headlines
