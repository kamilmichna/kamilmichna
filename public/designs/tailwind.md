## Overview

Tailwind CSS's design system is clean, modern, and developer-friendly. The indigo primary creates a tech-forward feel. Rounded corners and generous spacing make the interface approachable.

## Colors

Indigo (#6366F1) as the primary accent on a clean white surface. The palette is functional with semantic colors for different states.

## Typography

Inter with varying weights for clear hierarchy. Code fonts for technical content maintain the developer-focused aesthetic.

## Do's and Don'ts

1. **Do** use indigo for interactive elements
2. **Don't** add unnecessary decoration — clarity is key
3. **Do** embrace generous border-radius
4. **Don't** use more than 2-3 colors per view
