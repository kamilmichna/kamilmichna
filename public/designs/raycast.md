## Overview

Raycast's design is sharp, focused, and productivity-oriented. Dark surfaces with precise spacing create a tool that feels fast and efficient. Every element has purpose.

## Colors

Deep dark (#1D1D1F) with coral red (#FF6363) as the primary accent. The palette is minimal but impactful.

## Typography

Inter at small sizes for density. JetBrains Mono for code and technical content.

## Do's and Don'ts

1. **Do** keep the interface dense but readable
2. **Don't** add decorative elements — speed is the aesthetic
3. **Do** use consistent 12px spacing
4. **Don't** use large font sizes — density is key
